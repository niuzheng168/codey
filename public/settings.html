添加自己的节点

先选择目标系统、配置机器，再验通添加。Windows / Linux 使用 Azure 私网，macOS 使用私有 DevTunnel。

  1. 1

    按目标系统下载机器配置包

    包含临时机器身份、改版源码与安装脚本。Node 和软件依赖会自动下载安装。

  2. 2

    在 Codex 中配置目标机器

    解压后，让 Codex 使用 config-new-codey-machine/SKILL.md。Windows 执行 PowerShell，Linux/macOS 执行各自 Shell 入口，默认均先显示计划。

    支持范围与安全说明

    目标为 Azure Windows x64 或 Linux x64，需联网安装依赖。网络、防火墙与模型登录必须本人确认。Windows 服务仅在本人登录后运行，不安装 Linux 升级器；可达性使用真实 Workspace 健康检查。现有 Windows Dev Tunnel 节点不需重新安装。

    macOS 通过本人登录的 DevTunnel 主动连接，不开放入站端口，不需要 Azure VM 或节点后台的 Azure 部署权限。安装独立 CloudCLI/HTTPS 数据服务与 launchd 登录服务，复用现有 Codex 和本机模型代理，不修改其配置。令牌自动续期，仅绑定本节点。

    每次下载预留一个七天有效的机器身份，尚不加入节点列表。包内含本次专属密钥，请勿分享。

  3. 3

    验通并添加机器

    上传 Skill 生成的 codey-machine.json，不是 ZIP、SHA-256 或 enrollment。门户验证 VNet/DevTunnel、节点身份与 Workspace 后才加入列表；机器文件不含密钥或连接令牌。

待配置身份

配置包含机器专属密钥，请仅在自己的机器上使用，不要分享。

本节点接入资料

只复制到你自己的节点，不要分享这些密钥。既有 zhn 节点无需改动；新节点的 Workspace 还需部署 CloudCLI 并由运维配置可信私网网关。
