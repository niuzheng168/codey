添加自己的节点

下载同一份 Codey 安装 Skill，在目标机器配置私有 DevTunnel，再上传注册文件。无需在这里选择系统。

  1. 1

    下载 Codey 安装 Skill

    Linux x64 / Windows x64 共用一个 codey npm 包，包含 Workspace 与网关。Skill 内附安装脚本，不含 token 或机器身份，可分发到多台机器。

    正在检查 Codey 共用安装 Skill…

  2. 2

    在目标机器执行 Skill

    解压 Skill 后，让目标机器的安装助手按 SKILL.md 执行，识别系统并选择安装步骤。应用始终通过 npm 安装，不要手工解压 .tgz。

    仅安装运行包不等于节点已接入；还需完成私有 DevTunnel、模型登录和机器注册。

    支持范围与安全说明

    共用运行包支持 Linux x64 / Windows x64。Linux 包含完整托管部署；Windows 安装保留现有服务与 DevTunnel 配置，不运行 Linux 的 codey setup。

    使用本人 GitHub 登录的私有 DevTunnel 主动连接，无需开放入站端口。每台机器独立生成私密凭据，模型登录另行完成。

    下载不会创建或刷新待配置身份。同一个固定 Skill 包可以复用分发，每台机器最终生成各自的私密注册文件。

  3. 3

    上传私密注册文件并添加机器

    上传已配置机器的注册 JSON（最多 32 KB；传输后文件名允许改变），系统类型由注册文件识别。此文件含私密凭据，只能上传到当前 HTTPS Portal；不要通过聊天、邮件或日志传递，添加成功后立即删除。

Skill 包可复用分发；每台机器生成的注册文件不可分享，且只应上传到当前 HTTPS Portal。

本节点接入资料

只复制到你自己的节点，不要分享这些密钥。新节点请使用 Codey 一键安装器配置私有 DevTunnel 并导入注册文件。
