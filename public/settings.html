添加自己的节点

1. 下载机器自动配置 Skill

先配置机器，最后再添加。轻量包包含你的临时机器身份、Codey 改版 CloudCLI / copilot-api 源码与安装脚本。Node 和软件依赖由命令自动下载、校验并安装，不再单独收集安装包或证书。

正在检查完整依赖包…

2. 在 Codex 中配置目标机器

解压后让 Codex 使用 config-new-codey-machine/SKILL.md。当前面向 Azure Linux x64，需要联网安装依赖；Windows Codex 可作为控制端。Skill 配置服务、HTTPS、SSO 与 VNet；Azure 权限和模型登录仍需本人授权。包内含本次专属密钥，请勿分享。

3. 配置完成后，验通并添加机器

选择 Skill 生成的 codey-machine.json（不是 ZIP、SHA-256 或 enrollment）。门户实际验证私网与 Workspace 后才将机器加入列表。
