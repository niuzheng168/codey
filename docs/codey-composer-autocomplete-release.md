## 发布中修正

1. 首次镜像保留了本地源文件 `0600` 权限，默认 root 归属使非 root 的
   Portal 进程无法读取入口。该失败修订没有取代原健康修订。
   Dockerfile 已改为 `COPY --chown=node:node`，并在 `USER node` 下检查所有
   运行输入的读权限，使同类问题在镜像构建阶段就失败。
2. 一次生产浏览器合成请求触发了原来的 `2000ms` 上游超时。
   实际生产上限调整为 `3000ms` 后完成桌面和触屏模拟验证；
   浏览器的 `4500ms` 请求上限、无自动重试和非阻塞输入规则均不变。
   这不代表每一次模型请求都能在 3 秒内完成；超时仍安静降级。
