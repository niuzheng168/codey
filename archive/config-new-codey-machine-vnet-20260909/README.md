# Archived VNet onboarding

This is the pre-DevTunnel onboarding snapshot from commit
`93381fd444e8295dbc093dad6285d1e2623fc210`, archived on September 9, 2026.
`archive-manifest.json` records the SHA-256 of every original file.

- Historical reference only; **not included in the active Skill or downloads**.
- Contains the Azure planner, Linux/Windows VNet installers and their supporting
  instructions. No enrollment, credentials, certificates or private packages.
- The original platform-specific instructions are preserved, including material
  outside the VNet path. This archive is not a complete DevTunnel package.
- Existing VNet nodes are not changed by the new onboarding flow.
- If VNet is needed again, review the topology, dependencies and authorization
  before restoring it. Never run this against an existing node as an upgrade.
